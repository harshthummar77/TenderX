## Notes for whoever picks this up

- The GSTINs are structurally valid with correct check digits
  (`27AAACM1234C1Z4` for Meridian, and one per vendor), because the server
  verifies the checksum. Generate more with `gstinChecksum` from `@tb/shared`.
- `CLOUDINARY_*` is present in `server/.env` but incomplete, so the server logs
  "Cloudinary is not configured; uploads are held in memory and lost on restart"
  and the KYC documents are in-process only. Re-upload them after a restart if a
  screen needs them, or finish the Cloudinary config.
- Sign-in is rate limited to **10 attempts per IP per 15 minutes** (plan 03 §7).
  Scripted logins exhaust it quickly; the store is in-process, so restarting the
  API resets it.
- Invitation tokens are stored hashed, so the raw link only exists in the email.
  With SMTP unset the console transport logs it — grep the server output for
  `accept-invite/` to get a working link locally.
